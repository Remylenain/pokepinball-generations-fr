# Pokémon Pinball Generations — version française

French translation of [**Pokémon Pinball Generations**][upstream] by huderlem.
This fork only adds the translation on top of the original project: gameplay is unchanged.

Traduction en français de [**Pokémon Pinball Generations**][upstream], le hack
de huderlem qui ajoute à Pokémon Pinball les tables et les Pokémon des
générations suivantes. Ce dépôt n'apporte que la traduction : le jeu lui-même
est inchangé.

* Branche `release/1.6-fr` : la version 1.6 (4 tables, 251 Pokémon) traduite.
* Branche `master` : la version en cours de développement d'huderlem (6 tables,
  386 Pokémon) traduite.

Les textes et la terminologie suivent la version européenne officielle de
Pokémon Pinball.

Pour compiler le jeu, voir [**INSTALL.md**](INSTALL.md). Aucune ROM n'est
distribuée ici.
